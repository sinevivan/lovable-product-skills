## Discovery
| № | Промпт |
|---|--------|
| 1 | **«Опиши 5 главных болей целевой аудитории в сфере {индустрия} и как они сейчас решаются. Укажи, какие задачи остаются неудовлетворёнными.»** |
| 2 | **«Сформулируй 3 гипотезы о потребностях пользователей, которые могут стать основой нового продукта в {категория продукта}.»** |
| 3 | **«Составь карту пользовательского пути (customer journey) для типичного клиента, начиная с осознания проблемы до покупки решения.»** |

## JTBD (Jobs‑to‑Be‑Done)
| № | Промпт |
|---|--------|
| 1 | **«Определи 3 ключевых «Job to be Done» для пользователя, который хочет {цель/задача}. Укажи контекст, триггеры и желаемый результат.»** |
| 2 | **«Сформулируй «Job Statement» в формате: Когда {ситуация}, я хочу {действие}, чтобы {цель}. Приведи 5 вариантов для {продукт/услуга}».** |
| 3 | **«Опиши, какие альтернативные решения пользователь рассматривает для выполнения данного JTBD и почему они могут быть недостаточны.»** |

## PRD (Product Requirements Document)
| № | Промпт |
|---|--------|
| 1 | **«Сгенерируй структуру PRD для продукта {название}. Включи: цель, пользовательские истории, функциональные требования, нефункциональные требования, критерии приёмки, риски и метрики успеха.»** |
| 2 | **«Напиши 5 пользовательских историй (User Stories) в формате: Как {роль}, я хочу {функция}, чтобы {выгода}. Для продукта {название}».** |
| 3 | **«Сформулируй Acceptance Criteria для функции {функция} в виде чек‑листа из 5 пунктов.»** |

## Анализ конкурентов
| № | Промпт |
|---|--------|
| 1 | **«Создай сравнительную таблицу 5‑х основных конкурентов в {рынок}. Включи: цены, ключевые функции, USP, слабые места, отзывы пользователей.»** |
| 2 | **«Составь SWOT‑анализ для конкурента {конкурент}. Укажи сильные/слабые стороны, возможности и угрозы в контексте нашего продукта.»** |
| 3 | **«Опиши, какие креативные стратегии (соц‑медиа, контент, рекламные кампании) используют топ‑3 конкурента и какие результаты они показывают (CTR, CPL, ROI).»** |

## MVP (Minimum Viable Product)
| № | Промпт |
|---|--------|
| 1 | **«Определи ядро MVP для продукта {название}. Перечисли 3‑5 обязательных функций, которые позволяют проверить гипотезу рынка.»** |
| 2 | **«Составь план разработки MVP за 6 недель: задачи, ответственные, сроки, критерии готовности.»** |
| 3 | **«Опиши метрики, которые необходимо измерять в течение первых 30 дней после релиза MVP (DAU, Retention, NPS, Conversion).»** |

## Приоритизация
| № | Промпт |
|---|--------|
| 1 | **«Сформулируй приоритеты функций по модели RICE (Reach, Impact, Confidence, Effort) для списка 10 функций. Выведи таблицу с расчётами и итоговым рейтингом.»** |
| 2 | **«Создай матрицу Impact‑Effort для всех запланированных задач и выдели «Quick Wins» и «Big Bets».»** |
| 3 | **«Определи, какие функции следует отложить, если ограничение – 3 млн ₽ бюджета и 2 мес. разработки.»** |
