# Presentation Workflow (Russian)

## 📋 Overview
This workflow guides the creation of a high‑impact presentation in Russian, from initial audience analysis to final quality assurance. Each stage includes **gates** (criteria that must be met before moving forward) and **prompts** (questions or instructions for the author/reviewer).

---

## 🗂️ Workflow Steps

| # | Stage | Description | Gate | Prompt |
|---|-------|-------------|------|--------|
| 1 | **Аудитория / Решение / Тезис** | Определите целевую аудиторию, ключевое решение/проблему и основной тезис презентации. | • Четко сформулированный **тезис** (≤ 1 предложение). <br>• Описание **аудитории** (роль, уровень, интересы). <br>• Выявлена **боль/цель** клиента. | *Кто будет смотреть презентацию?* <br>*Какую проблему мы решаем?* <br>*Какой главный тезис должен запомниться?* |
| 2 | **Narrative Deck (Сценарий)** | Создайте «скелет» из 5‑7 слайдов, раскрывающих историю от проблемы к решению. | • Логическая последовательность **проблема → анализ → решение → выгода → CTA**. <br>• Каждый слайд имеет **заголовок** и **ключевой месседж**. | *Какой порядок слайдов лучше раскрывает историю?* <br>*Какие ключевые сообщения нужны на каждом этапе?* |
| 3 | **Evidence Check (Проверка доказательств)** | Подтвердите каждый аргумент реальными данными, кейс‑стади или исследованиями. | • Для **каждого** утверждения есть **источник** (ссылка, дата, автор). <br>• Данные актуальны (не старше 2 лет). | *Какие цифры/факты подтверждают наш тезис?* <br>*Есть ли независимые источники?* |
| 4 | **3 Representative Slides (Три образцовых слайда)** | Разработайте три полностью оформленных слайда, представляющих разные типы контента (текст, графика, таблица). | • Слайды соответствуют **бренд‑гайдлайну**. <br>• Применены **визуальные принципы** (контраст, выравнивание, иерархия). | *Какой визуальный стиль лучше подходит для нашей аудитории?* <br>*Какие типы визуализации нужны для данных?* |
| 5 | **Design Approval (Утверждение дизайна)** | Дизайнер/бренд‑менеджер проверяют соответствие всем визуальным и стилистическим требованиям. | • **Все** слайды прошли проверку на **шрифты, цвета, логотипы**. <br>• Нет орфографических/грамматических ошибок. | *Соответствует ли дизайн корпоративным стандартам?* <br>*Есть ли замечания по читаемости?* |
| 6 | **Full Deck (Полный набор слайдов)** | На основе одобренного дизайна создайте полную презентацию (10‑20 слайдов). | • **Все** ключевые сообщения из Narrative Deck реализованы. <br>• Слайды логически связаны, переходы плавные. | *Есть ли пропущенные шаги в истории?* <br>*Нужны ли дополнительные примеры или детали?* |
| 7 | **QA (Контроль качества)** | Финальная проверка на соответствие требованиям, отсутствие ошибок и готовность к публичному показу. | • **Тестовый прогон** (презентер репетирует). <br>• **Проверка** на совместимость с целевыми платформами (PowerPoint, Google Slides). | *Все ли технические ограничения учтены?* <br>*Есть ли обратная связь от репетитора?* |

## ⏭️ Gate Details & Acceptance Criteria

### 1. Audience / Decision / Thesis Gate
- **Тезис**: 1‑2 предложения, измеримый, привлекающий внимание.  
- **Аудитория**: минимум 3 атрибута (роль, уровень, боли).  
- **Решение**: чётко сформулировано, отвечает на «Что мы предлагаем?».

### 2. Narrative Deck Gate
- **Структура**: 5‑7 слайдов, каждый со **заголовком** и **ключевым месседжем**.  
- **Логика**: каждый слайд логически следует из предыдущего.

### 3. Evidence Check Gate
- **Источник**: ссылка, дата, автор/организация.  
- **Актуальность**: не старше 2 лет (исключения – классические исследования).

### 4. 3 Representative Slides Gate
- **Типы**: <br>• Текстовый слайд (ключевой месседж). <br>• Инфографика/диаграмма. <br>• Таблица/список.  
- **Бренд**: цвета, шрифты, логотипы согласно гайдлайну.

### 5. Design Approval Gate
- **Визуальная согласованность**: одинаковый стиль на всех слайдах.  
- **Текст**: проверка орфографии, пунктуации, стилистики.

### 6. Full Deck Gate
- **Полнота**: покрыты все пункты из Narrative Deck.  
- **Переходы**: плавные, без «прыжков» в логике.

### 7. QA Gate
- **Тестовый прогон**: минимум 2 репетиции с записью.  
- **Техническая проверка**: открывается без ошибок в PowerPoint, Google Slides, PDF.

## 🛠️ Prompt Library (Russian)

Below is a reusable set of prompts for each gate. Copy‑paste them into your collaboration tool (Notion, Confluence, Slack, etc.) and adapt as needed.

### Audience / Decision / Thesis
```
1️⃣ Кто является целевой аудиторией? (роль, уровень, интересы)  
2️⃣ Какую проблему/цель мы решаем?  
3️⃣ Какой главный тезис должен остаться в памяти?  
4️⃣ Какой результат/действие мы хотим от аудитории?
```

### Narrative Deck
```
Опишите последовательность слайдов:
1. Проблема  
2. Анализ (данные, инсайты)  
3. Предложение решения  
4. Выгоды/ROI  
5. Призыв к действию (CTA)  

Для каждого слайда укажите заголовок и ключевой месседж.
```

### Evidence Check
```
Для каждого утверждения укажите:
- Источник (ссылка, дата, автор)  
- Краткое резюме доказательства  
- Почему это релевантно аудитории?
```

### 3 Representative Slides
```
1️⃣ Текстовый слайд – какой главный месседж?  
2️⃣ Инфографика – какие данные визуализировать?  
3️⃣ Таблица/список – какие сравнения нужны?  

Укажите желаемый стиль (цвета, шрифты) согласно бренд‑гайдлайну.
```

### Design Approval
```
Проверьте:
- Соответствие фирменным цветам и шрифтам  
- Наличие логотипа и его позиционирование  
- Читаемость текста (контраст, размер)  
- Отсутствие орфографических ошибок
```

### Full Deck
```
- Все ли пункты из Narrative Deck реализованы?  
- Есть ли логические «провалы»?  
- Нужно ли добавить примеры/кейсы?  
- Какой порядок слайдов оптимален для повествования?
```

### QA
```
1️⃣ Протестировать открытие файла в PowerPoint, Google Slides, PDF.  
2️⃣ Провести 2 репетиции с записью.  
3️⃣ Собрать обратную связь от коллег (мин. 2 человека).  
4️⃣ Исправить найденные недочёты и подтвердить готовность к показу.
```

## 📦 Deliverables
- **Аудитория/Тезис** – 1‑страничный документ.  
- **Narrative Deck** – .pptx/.pdf (5‑7 слайдов).  
- **Evidence Sheet** – таблица с источниками.  
- **3 Representative Slides** – отдельные файлы/скриншоты.  
- **Full Deck** – финальная презентация (10‑20 слайдов).  
- **QA Report** – чек‑лист с результатами тестов.

---

## 🚀 How to Use
1. Clone the repository.  
2. Open `workflows/presentation-workflow.md`.  
3. Follow the steps sequentially, completing each gate before proceeding.  
4. Use the prompts to gather required information and to conduct reviews.  
5. Commit the artifacts to the appropriate folder (`/assets/presentations/…`).  

Happy presenting!
